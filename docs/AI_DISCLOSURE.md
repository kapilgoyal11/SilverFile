# AI-use disclosure

We used Claude, Anthropic's AI model, throughout this assignment. Team members used it to help write and debug the code for their agents and tools, including the review console, the filled 1040-SR PDF generator and the Docker setup, and to draft our documentation: the run guide, the demo case files, the architecture figure, the slides for the demo video and early versions of the five-page report. In some sessions Claude could read the repository and run the code and tests directly. Nothing went in on the model's word: each owner read, ran and tested their code before it was merged, and pull requests were reviewed before merging. In one of those reviews Claude flagged that the Docker port should be bound to 127.0.0.1 and that the run guide had to say plainly that offline mode uses saved W-2 answer keys, and both changes were made. Every figure in the report was checked against real runs of the system. No model decided a tax rule or an amount: tax constants are cited to IRS publications or the brief, and all arithmetic is done by deterministic, tested Python. The code calls Claude at run time only if an Anthropic API key is supplied, to read W-2 images and, optionally, to give Eligibility a second opinion. We supplied no key, so no model was called during any run, test or measurement.
